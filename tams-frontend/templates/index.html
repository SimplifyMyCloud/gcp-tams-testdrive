About TAMS

TAMS (Time Addressable Media Store) is an API specification for storing, querying, and accessing segmented media using time-based addressing. It enables:

  • Time-based media indexing and retrieval
  • Efficient cloud-native media storage
  • Content-centric workflows
  • Immutable media segments with unique timestamps
